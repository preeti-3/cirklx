# CirklX website

Figma-led rebuild of the CirklX marketing website using Next.js App Router, TypeScript, Tailwind CSS, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm run build
```

The contact form uses EmailJS and requires the existing public EmailJS environment variables to submit.
